# Changelog

Todos los cambios notables en este proyecto se documentan en este archivo.
El formato sigue las directrices de [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/)
y cumple con [Semantic Versioning](https://semver.org/lang/es/).

## [2.0.0] - 2026-09-27
### Añadido
- Módulo de criptosistemas modernos: simulador de red de Feistel (DES) y transformaciones de estado AES-128.
- Laboratorio de integridad hash y efecto avalancha con distancia de Hamming.
- Simulador de firma digital RSA educativa con detección de manipulación en tránsito.
- Explorador interactivo de la cadena de confianza PKI y certificados X.509.
- Suite de regresión automatizada con 23 pruebas unitarias y de simetría (`npm test`).
- Documentación formal de arquitectura de seguridad SSDLC (`SECURITY.md` y `ARCHITECTURE_AND_SECURITY.md`).
- Asistentes pedagógicos especializados para resolución paso a paso en Quiz (`PracticePlayfairAssistant`, `PracticePolybiusAssistant`).

## [1.0.0] - 2026-09-01
### Añadido
- Simulador interactivo del Disco Cifrador de León Battista Alberti en SVG.
- Criptosistemas clásicos: César, Afín, Vigenère, Playfair, Hill y Escítala/Columnar.
- Motor de criptoanálisis estadístico: test de Kasiski e índice de coincidencia de Friedman.
- Matriz de decisión comparativa y enciclopedia criptográfica interactiva.
- Despliegue automatizado en GitHub Pages con GitHub Actions.
